## 使用变化

在 Telegram 执行 `/start` 可刷新常驻九宫格。旧消息不批量改写，刷新或重新打开后显示新版。

拦截卡使用“网站拒绝：已记录 N 次（抽样）”“网站拒绝：本次未查到记录”“网站拒绝：暂时无法查询”。名单成员与实际拦截继续分开；记录覆盖有限时默认页保留提示，日志截尾、读取失败和扫描上限放入详情。模拟、非封禁处置和历史处置仍明确标识。

- 238 项测试全部通过，无跳过：执行证据 21、机器人 179、官方 Telegram 通知与路由 25、真实 Nginx/Lua 13。

真实通知使用私有临时配置和 loopback 接收器，将插件生成的 JSON 原样转发到配置目标，同时核对 HTTP 成功、JSON `ok=true` 和目标会话。机器人服务是唯一的 `getUpdates` 消费者；测试客户端使用独立诊断目录。
