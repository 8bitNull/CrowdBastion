# 使用体验改进与本地验收（2026-11-01）

用户在体验审查后授权实施建议。本轮在 `feat/user-experience-20261101` 增量修改，保留工作区既有部署修复及证据；未提交、推送或部署 VPS。

## 使用行为

- 安装向导根据已发现配置和当前服务状态标注进度，给已有部署优先检查入口；返回、取消和失败分别反馈，不把菜单操作记为完成。
- 核心／本地中转安装先校验管理员 IP，再预览系统、已有组件、软件包、配置、备份、服务和防火墙影响，默认取消。
- 推荐操作成功修改配置、启动／重新加载服务或恢复防火墙规则后自动只读复查。取消、只读说明及失败保留原页和错误。
- 交互检查显示阶段，技术详情支持固定安全分页；导出隐藏常见凭据、IP、URL 和终端控制符，文件权限 `0600`，拒绝覆盖及符号链接路径。分享前仍需人工核对域名、路径和业务信息。
- V2bX 持续记录菜单第 `5` 项及 `--prepare-v2bx-observer` 生成单源 JSON，复用真实服务校验器，确认后私有原子创建。同一菜单记住路径；启动服务另行选择。
- Docker bridge 展示网关、精确监听和容器工具前提，登记时按网络、监听、容器 LAPI、容器 AppSec 四阶段给出反馈。
- 中转验收保存范围、时间、人工确认结果及配置指纹，省略测试／对照来源 IP。超过 24 小时或配置变化提示重验；历史记录不改变当前健康结论。
- 首页新增 `5` 常用操作；`--runtime-status` 比较源码和维护副本，`--sync-runtime` 确认后同步脚本及 lib，保留 cron 原文和原执行时间。帮助前置常用入口，保留完整参数和旧编号。

操作说明见[使用说明](../usage-guide.md)、[CLI 参考](../cli-reference.md)、[V2bX 指南](../v2bx-guide.md)和[中转模式](../relay-mode.md)。
