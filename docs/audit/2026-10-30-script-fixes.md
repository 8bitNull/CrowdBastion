## 第二轮：沿共同失效模式继续修复

- 宿主机 Web Bouncer 安装与回滚同样改用已验证的重载，未确认旧配置恢复时保留软件包新增账号。
- Docker AppSec 接入和 AppSec 停用均增加信号事务回滚；停用前逐一确认网站接受新配置，不能确认时保留引擎。核心已经重启后发生中断，会恢复引擎配置并重新加载。
- 通知回滚若无法停止服务或取消启用，会保留当前程序、unit、配置和修改前备份，明确报告恢复不完整。
- 守卫解析拒绝 YAML 合并键、非映射根节点和编码错误，并统一返回受控校验错误。
- 通知接收器过载测试修正 TCP 提前关闭导致的竞态：允许 HTTP 503 或连接写入失败，同时直接读取 503、确认未生成第 17 个处理线程，并验证容量释放后的恢复。
- 工作流测试增加真实重载验证后，原 5 秒总时限在并行运行时出现三项超时。测试夹具总时限调整为 15 秒，重载验证自身的 10 秒截止时间保持不变；相关用例已定向复测通过。
