# 智能首页与任务流程交付记录

日期：2026-11-04。

## 本轮行为

无参数启动改为先只读识别现有部署，显示当前范围、检查时间和一个推荐任务。首页为推荐任务、日常管理、调整防护目标、高级工具；原高级管理内部编号与专项 CLI 保留。

业务目标和续办记录使用私有版本 1 JSON，保存与修改复用现有管理锁。任务根据当前证据和依赖推进；返回 0、配置变化或用户按过继续不单独标记完成。支持暂缓、复查和重新启动后的核对续办。

网站按实际 Nginx/OpenResty 运行实例选择并传递目标，明确同实例多个域名可能共同受影响。接入与真实 IP 使用已有验证器；bridge 连接根据当前网络、精确监听和容器内连通性核对，登记存在不代表通过。基础安装先收集输入、预览和确认，再取得锁核对配置、当前目标与任务前提。

现有组件故障不随目标变化隐藏；本机核心和远端登记同时存在时，可确认本次维护范围，不自动迁移。流程记录不安全时保留只读诊断，诊断不提供服务启动。既有入口验收按时间、配置及具体范围消费和展示，不扩展为全部流量健康结论。

## 限制与实现取舍

- 网站现有后端部分作用于整个运行实例，未增加逐域名配置隔离。
- 专项网站、远端和防火墙工具保留各自输入、确认与恢复流程，部分步骤仍需要技术信息。
- 网站内置请求测试仍只提供辅助证据；实际验收需关联外部请求、真实 IP 和具体规则日志，证据不足保持待验证。
- 后续循环复审已将暂缓证据限定到相关组件、实例和检查；辅助测试及能力说明可以有限记录完成，仍不升级为真实防护验收。
- 本轮验证不包含真实 VPS 软件包安装、生产重载、公网数据面或攻击流量验收；未部署到生产。
