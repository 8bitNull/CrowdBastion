# 中转入口引导验收验证（2026-10-14）

本轮补齐中转优先的验收流程：普通用户按步骤确认外部连接，脚本只读核对本机证据，最后给出一个限定到本次入口的结论。

## 行为

- 新增 `--verify-relay` 和菜单 `4 → 3 → 3`。声明目标 IP、端口、TCP/UDP、IPv4/IPv6、INPUT/FORWARD，以及独立测试来源与正常对照来源。
- 按封禁前可达、短时决策同步、封禁期间对照、到期退出集合与恢复四步引导。TCP 要求新连接与业务响应；UDP 要求应用响应。
- 只生成带唯一原因、有效期 `2m` 的决策命令，由操作者执行。远端模式明确仅在检测中心执行；向导不调用 cscli、不访问中心、不使用或输出连接密钥。
- 自动检测的 SSH 管理来源与手填管理来源同时受保护。拒绝测试来源与管理／对照／目标重合、对照来源与目标重合及来源地址族不一致；不确认共享来源时停止。
- nftables 证据限定到正确表、地址族与直接挂钩的链。支持官方来源集合后缀、IP／网段／范围元素、命名和匿名计数；只接受单个来源匹配、随后计数和最终 DROP/REJECT 的规则。
- 额外协议、端口、接口或连接状态条件、多集合条件、匹配前计数、自定义跳转、Docker bridge 和 iptables/ipset 保持未完成。计数缺失、减少或规则替换不视作增长证据。
- 通过需要全部外部对照与本机集合／计数／恢复证据齐全。输出一次“本次入口验证通过（人工确认）／本次入口验证未通过／验证未完成”，显示范围与来源；分别返回 `0`／`1`／`2`，Ctrl+C 返回 `130`。
- 取消、EOF 或中断后，未确认集合退出时提示等待本次决策到期并核对恢复，不按 IP 批量删除决策。已确认失败的结果优先于后续证据不足。
- 本地中转安装、远端 Bouncer 安装成功后自动只读检查；终端中可以选择验收。后续检查异常或取消不改写成功安装的返回码。静态健康总结继续保留实际拦截待验证。
- README 保留操作入口，准备条件、四步流程、结论与支持范围放在中转指南；CLI 和使用说明同步更新。
