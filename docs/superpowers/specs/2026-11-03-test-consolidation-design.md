# 测试收敛设计

用户已确认按测试分层、公共夹具、耗时统计推进。沿用 unittest 和现有依赖，不按数量删用例，也不改生产代码或 VPS。

方案：相比直接删除形似用例，或引入 pytest/并行执行，本轮增加薄的 unittest 入口与显式模块清单；完整发现仍是发布基准。quick 是精选核心回归子集，integration 是环境依赖专项，archive 是节点历史回归；full 包含所有模块，已有 discover 命令继续有效。专项不代表真实攻击验收。清单错误或未知模块必须报错。

公共夹具提取为不继承 TestCase、无 test_ 方法的 WorkflowFixtureMixin。保留现有测试类和测试 ID，继承测试类的两个消费者改为 mixin + TestCase；其它消费者直接引用 mixin。每个用例仍有独立临时树，不共享可变状态。

新入口支持只列出测试、按模块筛选、逐项耗时 JSON、慢项摘要、可选禁止 skip。默认 full。报告保留跳过原因、失败状态和退出码；不根据上一次耗时自动选择或隐藏测试。新入口自身用小型临时测试集验证，避免为其重跑整仓。

验收：原 1655 项测试 ID 和方法实现哈希不变；补充入口自测；基线及最终全量运行；记录 quick 实测耗时和慢项来源。历史审计证据原样保存；在隔离快照中工作，再按基线哈希检查后仅交付本轮文件，不提交或部署。
