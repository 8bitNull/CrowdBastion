# 远端 LAPI / Bouncer-only 中转设计

用户已授权执行上一阶段建议：先真实中心 LAPI 验证，再提供 Bouncer-only 安装及维护。

中心运行官方 CrowdSec，独立中转网络节点运行官方 Firewall Bouncer。只在无外网 NIC、无宿主目录共享的 QEMU 客机内修改测试防火墙。复用现有 gost/realm/NAT 网络验收拓扑和实际数据包探针；将模拟决策 API 替换为真实 LAPI，使用 cscli 增删决策。验证同步、封禁计数器、正常客户端、不再封禁、短期决策过期，中心断连及恢复，错误密钥与服务重启。结果必须报告实际观测，不能将 fixture 或静态规则描述成真实远端验收。

新增独立 Bouncer-only 安装、修改、只读状态及卸载入口。沿用已有平台、包管理、配置事务及互斥锁。输入远端 URL 和隐藏密钥；校验 URI（无用户信息/查询/片段），禁止输出密钥或将密钥放入命令参数。配置文件 root-only。预检真实决策 API 的认证，超时必须有界；默认拒绝公网明文 HTTP，可允许环回/私网 HTTP 并在文档建议 WireGuard/TLS。失败回滚已有配置和服务状态；不自动卸载、停止或改变已安装核心，不自动授权远端账号，不修改其他 Bouncer。已有 .local 覆盖必须识别。卸载仅处理本工具管理的远端 Firewall Bouncer 配置/包，遇非托管配置须拒绝。

仅运行 Bouncer 不采集 SSH 日志、不识别新的 SSH 攻击。日志集中传递需用户自行建立独立可信通道，文档明确源 IP 丢失限制。不能承诺防止流量型 DDoS，不能把短时模拟当作长期稳定性或线路带宽测量。

保留当前工作区全部已有修改，不提交、不触碰宿主防火墙或安装宿主包。
