# 引导式终端交互

用户已确认整体梳理交互，保留底层功能和命令行入口，先做顺常用路径。

首页提供：1 检查防护情况，2 安装或调整防护，3 管理封禁与放行，4 高级管理，0 退出。原分类菜单移入高级管理，保留其内部编号；启动横幅缩短。首次选择用途后进入用途引导，不自动安装。

安装引导按保存用途显示步骤、作用及对应操作，支持组合用途；选择具体步骤才调用原安装函数，写操作沿用管理锁和原确认。纯落地不强制安装本地 CrowdSec，远端执行不安装本地核心。提供直接检查入口。未选择用途时先选择，取消或 EOF 返回。

检查保留严格证据判定和 CLI 退出码。默认结果先说是否需要处理，再说首要问题、影响与下一步；报告列出所有关注项的数量，避免混合类型漏计。技术输出仍收进详情。交互检查提供排查、详情、重新检查和返回；操作完成后留在流程中，并提示重新检查。

服务排查读取 systemd 状态、启动错误和配置校验，解释能确定的状态。检测服务仅在配置校验通过且服务已明确停止时提供确认启动；防火墙执行节点仅在明确停止时提供确认启动。不会自动修复未知配置，也不把一次启动成功当成拦截验证通过。

不新增依赖，不改现有部署、防护判断或 CLI 名称。同步首页、检查结果和菜单路径文档，测试真实终端导航、取消、EOF、用途分派、只读排查、确认启动及复查。
