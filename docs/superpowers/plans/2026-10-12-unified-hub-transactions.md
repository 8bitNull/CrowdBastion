# Hub 事务统一计划

**目标：** 用户已授权的第三轮合并：更新、集合安装及移除共用锁、持久快照、变化检测、校验、加载和失败恢复。

**结构：** `lib/hub_maintenance.sh` 负责事务生命周期；`crowdsec_hub_snapshot.py` 提供文件级差异及冲突保护；`crowdsec_maintenance.py` 提供统一持久快照入口并兼容历史快照。集合安装暂存事务，最终由已有核心加载入口提交，失败或退出则恢复。

**边界：** 不回滚系统软件包、运行数据库/WAL、网站配置及外部并发操作；不改命令行参数。未知文件、符号链接和恢复冲突必须保留并报告。组合基础修复保持最后仅加载一次。
