# 三内核混合入口与应用载荷实验验收

用户已授权继续执行多用户同时直连／中转、IPv6 和 UDP 应用载荷验收。本阶段只扩展隔离实验，不安装生产规则或替换生产二进制。

- 在无 NIC、无共享目录的 QEMU 客机中复用独立网络／挂载命名空间，分配不同 IPv4/IPv6 用户与中转 peer。
- 使用此前最终实验构建、真实 sing-box 客户端、受控双账号面板；覆盖 13 个基础 core/protocol 组合与两个地址族。
- 每组合以正常基线、正常直连和中转并发错误凭据、恢复三个阶段验证。有效账号不同；错误账号不应收到随机回显载荷。
- TCP CONNECT 与 SOCKS UDP ASSOCIATE 均验证随机应用载荷；地址族同时用于外层入口和后端应用目标。测量实际请求区间重叠，不将线程启动当作并发证据。
- 将未成功的 UDP 转发独立列为缺口；不得因为 QUIC 外层使用 UDP 而推断 UDP 应用可用。
- 固定事件只归因实际 peer；共享中转排除；检查健康 peer 未成为认证失败告警来源。实际投影进入官方 CrowdSec 隔离引擎，严格核验预期来源／内核／协议组和零决策。
- 独立审查探针与证据；保留不合格轮次的摘要。归档脚本、固定投影、结果及哈希，不保存原始配置、原始业务日志、私钥或程序二进制。

边界：不是生产公网验收，不代表所有传输／密码套件／负载规模；没有测试容量阈值、带宽清洗、自动封禁或正常峰值负载。
