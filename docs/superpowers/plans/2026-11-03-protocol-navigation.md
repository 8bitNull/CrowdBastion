# 多协议使用导航调整计划

**目标：** 让新增协议指导可从现有交互菜单到达，无需预先设置环境变量；V2bX专项检测与通用指导分开，旧编号、CLI和roles v1兼容。

**设计与执行选择：** 采用增补通用导航和交互式声明选择器；仅修改现有文字会保留环境变量门槛，整体重排菜单会破坏旧路径，因此不采用。沿用Bash菜单与现有Python画像，不持久化程序/协议声明，不安装代理程序。使用已有隔离工作区，由主任务实施并经独立复审，不提交/推送/部署。

**全局约束：** 声明不是运行证据，V2Node版本仍未知；不改变默认防护/网络/roles配置。所有旧菜单数字与命令语义保留。通用协议画像只读且不取得修改锁；进入明确修改子菜单仍沿用原确认与锁。缺少传输不推断TCP，TLS只代表安全层。取消/EOF不执行变更，输入只接受编号，用户环境变量不被永久改变。
