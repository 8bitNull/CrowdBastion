# 导航优化与行为保持渐进重构

**目标：** 执行用户授权的“优化—行为保持—渐进重构—回归”循环，降低通用导航与V2bX耦合，统一事务操作入口，保持外部行为。

**方法：** 原生Bash/Python，不更换菜单框架；沿用已实现导航作为行为基线。由主任务顺序实施，每轮先记录真实菜单输出/退出码/操作轨迹/配置快照，再做小幅提取并对照。最后独立复审、全仓回归一次，按摘要同步。无需重复设计审批；不提交、推送或操作VPS。

**约束：** 旧编号、命令、roles v1、完整输出、取消/EOF、状态码及确认/锁顺序保持；未知传输不推断TCP，协议指导不扩张日志检测；不修改防火墙/网络算法、凭据或实际业务配置。只读入口不加锁，修改仍通过原确认和锁；失败退出码不被格式化吞掉。

- [x] 将通用协议导航函数原样移到lib/protocol_guidance.sh，主脚本加载新模块，V2bX专项函数及旧命令不变。
