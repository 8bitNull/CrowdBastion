## 全局约束

- 保留已部署 CrowdSec backend、账号、密钥、业务配置和管理员连接；状态查询不修改服务、配置或防火墙。
- 不根据一次超时认定认证失败或调优失效；用固定错误码、阶段和耗时提供证据，不输出 URL 凭据、业务原始日志或 secrets。
- 环境前置检查使用有界轻量采样，不以一次历史平均或读取日志超时替代系统根因判断；不承诺可立即终止内核 D 状态进程。
- 已有 roles v1 继续兼容。协议、程序、传输方式、直连/共享中转分别表示；来源不明保持 unknown，不自动推断允许列表或封禁共享中转。
- 公网访问策略仅作用用户明确选择的端口/协议/入口接口；支持双栈和 Docker 原始目标端口，保留 CrowdSec 首条；无整表 flush/restore，保护管理入口。
- 变更计划只读；应用有 root 私有备份、稳定完整运行副本、不可变 manifest、共同锁、漂移保护、独立回退定时器。单项回退失败继续恢复其他项，未确认全部恢复成功不能取消后续回退机会。
- 网络调整独立可选，默认安装不自动调参；不按内存固定比例压缩 tcp_mem、不为 UDP/QUIC 套用 TCP 算法，不把默认值恢复称为吞吐提升。
- 输出区分运行检查、决策入核、实际阻断、性能测试；归档不依赖临时目录，可离线重算。
